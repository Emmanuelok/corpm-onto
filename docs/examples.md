# Examples

The repository includes three synthetic example datasets:

- procurement collusion during bid evaluation
- variation order manipulation during implementation
- inspection fraud during payment certification

All examples are synthetic and exist only to demonstrate ontology population, validation, and querying workflows.

See:

- `data/examples/synthetic-project-case-001.ttl`
- `data/examples/synthetic-procurement-risk-example.ttl`
- `data/examples/synthetic-variation-order-example.ttl`
