# corruptpm-ontology

`corruptpm-ontology` is a modular ontology and tooling project for analysing corruption in project management as a connected lifecycle phenomenon rather than a flat list of misconduct labels.

The project bundles:

- OWL/RDF ontology modules in Turtle
- SHACL validation
- SPARQL competency questions
- synthetic case data
- a Python CLI for loading, validating, querying, exporting, and generating artifacts

Use this documentation alongside `README.md` when working in the repository.
