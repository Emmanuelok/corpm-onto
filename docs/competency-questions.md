# Competency Questions

The `queries/` directory includes runnable SPARQL files for questions such as:

- Which corruption risks are associated with each project lifecycle phase?
- Which corrupt acts commonly occur during procurement?
- Which actors are involved in a given corruption event?
- Which red flags indicate potential bid rigging?
- Which controls mitigate a specific corrupt act?
- Which barriers inhibit control implementation?
- Which impacts result from variation order manipulation?
- Which contract stages are vulnerable to invoice fraud?
- Which indicators are linked to low competition?
- Which controls are detective rather than preventive?
- Which actors can play oversight roles?
- Which risks occur in land acquisition and compensation?
- Which controls are relevant to digital traceability?
- Which red flags are linked to payment manipulation?
- Which synthetic case examples involve procurement corruption?

Run a query with:

```bash
corruptpm query queries/cq18_red_flags_for_bid_rigging.sparql
```
