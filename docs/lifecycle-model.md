# Lifecycle Model

The lifecycle model includes:

- conception
- feasibility and pre-investment
- planning
- design
- land acquisition and compensation
- financing and budget allocation
- procurement
- procurement of professional services
- construction or implementation
- inspection
- monitoring and evaluation
- handover and commissioning
- operation and service delivery
- maintenance
- closeout

The ontology encodes lifecycle-specific risk, act, red-flag, and control patterns through subclass restrictions so SPARQL queries can inspect them directly.
